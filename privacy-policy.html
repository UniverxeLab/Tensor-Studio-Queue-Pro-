Studio Queue & Bulk Downloader for Tensor.art is a local-first Chrome browser extension that helps creators organize prompt batches, synchronize generation controls inside tensor.art, and save their own generated images/videos, prompt sidecar .txt files, catalog.csv logs, and ZIP archives directly to their computer.

1. Data We Do NOT Collect

  • We do not run third-party analytics, ad pixels, behavioral trackers, or session recorders.
  • We do not sell, rent, share, or transfer any user data to advertisers or data brokers.
  • We do not upload your prompts, negative prompts, style presets, generated outputs, Tensor.art account credentials, cookies, or browsing history to any remote server — we operate zero backend prompt-logging or scraping infrastructure.

2. Data Stored Locally in Your Chrome Profile

To keep your presets, queued items, and preferences across browser restarts, the extension saves data locally inside Chrome's built-in chrome.storage.local storage on your device:

  • Your custom style presets, prompt queue items, template variables, and pacing/Energy Guard settings.
  • Scanned gallery metadata (output URL, prompt snippet, timestamp, favorite ★ state) and daily free quota count.
  • Local creator XP rank / streak counters, 24-hour Pro Pass flag, and optional selector calibration overrides.
  • Your Pro license key (only if you voluntarily enter one in Setup & Pro) and its cached verification result.

You can erase stored gallery/queue state anytime via Clear inside the extension, or remove all extension data completely by uninstalling the extension in Chrome.

3. Chrome Permissions & Strictly Scoped Access

  • storage: Persists prompt templates, active queues, gallery index cache, local XP counters, and license state inside your local browser profile.
  • downloads: Saves selected outputs, .txt prompt metadata files, catalog.csv, and structured .zip bundles into your local Downloads/TensorQueue/ folder when you click Download or enable auto-download.
  • sidePanel: Renders the extension panel cleanly beside your active Tensor.art browser tab.
  • scripting: Used strictly as a fallback/recovery helper to attach content script controls on an already open tensor.art tab without forcing a manual reload.
  • Host access (https://*.tensor.art/*, https://*.tensorartassets.com/*, https://*.tusiassets.com/*, https://*.r2.cloudflarestorage.com/*): Restricts DOM interaction solely to Tensor.art Studio pages and permits client-side media fetching of your own generated workspace files solely when packaging user-requested ZIP exports. Never runs on unrelated websites.

4. Optional Pro License Verification (Lemon Squeezy)

Using the Free tier and 24-hour milestone Pro Pass makes zero external license network requests. If you purchase a Starter Pro or Early-Bird Lifetime key and click Activate Pro, the extension transmits only the license key you entered and a non-identifying Chrome instance label to Lemon Squeezy's official license API (api.lemonsqueezy.com) solely to validate license status and device activation limits. Payment card details are processed exclusively by Lemon Squeezy (Merchant of Record) under Lemon Squeezy's Privacy Policy.

5. Chrome Web Store Limited Use Compliance

The use of information received from Google/Chrome APIs strictly adheres to Chrome Web Store User Data Policy, including Limited Use requirements: data is used solely to deliver the documented batch workflow and local download features inside the extension interface.
